# CIS-DF Quizlet — 223 questions

Open index.html. All 223 PDF questions and their answer variants are included, in PDF order. Uses the unchanged NQ8 stylesheet and quiz engine, with a separate progress key. Single-choice and multiple-choice questions, Check answer, Show answer, Try again, learning status, navigation and dashboard work as in NQ8.

Eight corrections are documented in explanations with ServiceNow sources. Unlettered PDF options have consecutive letters restored. Other answers retain the supplied PDF key; no full external audit is claimed.

NQ8 source was read only and not changed. questions.json is an inspectable copy of the embedded question data.
